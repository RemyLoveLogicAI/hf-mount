## Overview

This directory holds deployment artifacts used to provision a virtual private server (VPS) specifically for installing and configuring the hf-mount tooling. At the root level there is a single Bash script (vps-setup.sh) that automates the installation and configuration steps required on a fresh VPS. The script is intended to be the primary, and currently only, mechanism for performing the deployment tasks in this directory.

Because there are no subdirectories, the structure is intentionally minimal: one executable script encapsulates the deployment logic for hf-mount. The role of this directory in the larger repository is to provide an operational entry point for system administrators or automation pipelines that need to prepare a server with hf-mount — it centralizes the server-side setup steps so other parts of the system can assume a consistent runtime environment after the script has run successfully.


### File Organization

This directory uses a flat structure with a single root-level deployment script. The layout keeps all VPS installation logic in one place (vps-setup.sh) so maintainers have a single entry point to update or run when provisioning servers for hf-mount.
